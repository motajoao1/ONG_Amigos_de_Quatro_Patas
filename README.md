# ONG Amigos de Quatro Patas

Página estática responsiva em HTML e CSS, pronta para publicar no Vercel.

## Estrutura

- `index.html`: conteúdo da página
- `style.css`: estilos e media queries
- `images/`: quatro imagens usadas na página

## Publicação no Vercel

Importe a pasta deste projeto no Vercel como **Other** (sem framework) e mantenha a configuração de build vazia. O arquivo `index.html` será servido na raiz. Também é possível publicar via terminal dentro da pasta com `vercel --prod` após configurar a CLI.

Para abrir localmente, basta abrir `index.html` no navegador.

As imagens foram geradas para este projeto e estão incluídas localmente. Não há dependências, JavaScript ou serviços externos.
